# Calculadora de Desarrollos y Bobinas 🛠️

Una herramienta web ligera y rápida diseñada para calcular la longitud total de material en una bobina basándose en sus diámetros y el número de vueltas.

## 📋 Características

-   **Archivo Único Potente**: Todo el proyecto (HTML, CSS, JS) está contenido en un solo archivo `index.html`. No requiere instalación, servidores, ni procesos de compilación.
-   **Diseño Optimizado**: Interfaz oscura moderna, ideal para entornos de taller y uso prolongado.
-   **Responsive**: Funciona perfectamente en móviles, tablets y escritorio. Teclados numéricos optimizados para entrada rápida de datos.
-   **Cálculo Instantáneo**: Resultados en tiempo real (metros y milímetros) mientras escribes.

## 🚀 Uso Inmediato

Simplemente descarga o clona este repositorio y abre el archivo `index.html` con cualquier navegador web moderno (Chrome, Firefox, Safari, Edge).

¡No necesitas internet para usarla una vez descargada!

## 🧮 Cómo Funciona

La calculadora utiliza la fórmula geométrica para espirales/bobinas:
1.  Introduce el **Diámetro Exterior** (mm).
2.  Introduce el **Diámetro Interior** (mm).
3.  Introduce el **Número de Vueltas**.

La aplicación calculará automáticamente la longitud total del material desplegado.

## 🛠️ Tecnologías

-   **CSS3** (Variables CSS, Flexbox)
-   **Vanilla JavaScript** (Sin dependencias externas)
